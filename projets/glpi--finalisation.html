Finalisation et dépannage

Terminer l'installation depuis le navigateur et corriger la résolution du nom d'hôte.

1. Assistant d'installation web

Ouverture de l'adresse du serveur dans un navigateur, puis connexion à la base : serveur localhost, utilisateur glpi_adm et le mot de passe défini à l'étape de la base de données.

2. Première connexion

Une fois l'assistant terminé, la page de connexion de GLPI s'affiche : le serveur est opérationnel.

Dépannage : le nom d'hôte ne se résout pas

Symptôme : l'accès par l'adresse IP fonctionne, mais http://serveur-glpi échoue en local.

Solution : ajouter le nom dans le fichier /etc/hosts du poste, en face de l'adresse du serveur.

sudo nano /etc/hosts
