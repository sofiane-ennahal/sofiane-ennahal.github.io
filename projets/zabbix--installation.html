Serveur Ubuntu et paquets Zabbix 7.0

Préparer le serveur puis installer Zabbix depuis le dépôt officiel.

1. Préparation du serveur

Système : Ubuntu Server 24.04 LTS. Réseau : adresse IP statique 192.168.2.3/27, avec la passerelle du pare-feu pfSense. Mise à jour du système.

sudo apt update && sudo apt upgrade -y

2. Dépôt officiel Zabbix 7.0

Téléchargement et installation du paquet de dépôt pour Ubuntu 24.04, puis mise à jour de la liste des paquets.

wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_latest_7.0+ubuntu24.04_all.deb
dpkg -i zabbix-release_latest_7.0+ubuntu24.04_all.deb
apt update

3. Installation de l'ensemble

Serveur, interface web (PHP), configuration Apache, scripts SQL, agent local et base MariaDB, en une seule commande.

apt install -y zabbix-server-mysql zabbix-frontend-php zabbix-apache-conf \
  zabbix-sql-scripts zabbix-agent mariadb-server
