Base de données et configuration

Créer la base MariaDB, importer le schéma et renseigner le mot de passe dans Zabbix.

1. Base et utilisateur

Création d'une base « zabbix » en utf8mb4, d'un utilisateur dédié et attribution des privilèges. L'option log_bin_trust_function_creators est activée temporairement pour l'import.

mysql -uroot -p

create database zabbix character set utf8mb4 collate utf8mb4_bin;
create user zabbix@localhost identified by 'MotDePasse';
grant all privileges on zabbix.* to zabbix@localhost;
set global log_bin_trust_function_creators = 1;
quit;

2. Import du schéma

Injection de la structure des tables dans la base vide, puis retour à la valeur par défaut de l'option.

zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | \
  mysql --default-character-set=utf8mb4 -uzabbix -p zabbix

mysql -uroot -p
set global log_bin_trust_function_creators = 0;
quit;

3. Mot de passe dans le serveur Zabbix

Dans le fichier de configuration, renseigner le mot de passe de la base à la ligne DBPassword.

sudo nano /etc/zabbix/zabbix_server.conf
DBPassword=MotDePasse

4. Démarrage des services

Redémarrage pour appliquer la configuration, puis activation au démarrage pour la persistance.

systemctl restart zabbix-server zabbix-agent apache2
systemctl enable zabbix-server zabbix-agent apache2
