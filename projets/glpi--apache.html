Serveur web Apache

Créer un VirtualHost dédié, activer la réécriture d'URL et désactiver le site par défaut.

Principe

Un nom de domaine (même interne) est recommandé pour faciliter l'ajout futur d'un certificat SSL. Ici, le nom prévu est serveur-glpi.

1. Fichier du VirtualHost

sudo nano /etc/apache2/sites-available/serveur-glpi.conf
<VirtualHost *:80>
    ServerName serveur-glpi

    DocumentRoot /var/www/glpi/public

    <Directory /var/www/glpi/public>
        Require all granted

        RewriteEngine On

        # Redirige toutes les requêtes vers le routeur GLPI, sauf si le fichier existe.
        RewriteCond %{REQUEST_FILENAME} !-f
        RewriteRule ^(.*)$ index.php [QSA,L]
    </Directory>
</VirtualHost>

2. Activation du site et du module rewrite

Activation du nouveau site, désactivation du site par défaut devenu inutile, activation du module de réécriture utilisé par les directives RewriteCond et RewriteRule, puis redémarrage.

sudo a2ensite serveur-glpi.conf
sudo a2dissite 000-default.conf
sudo a2enmod rewrite
sudo systemctl restart apache2
