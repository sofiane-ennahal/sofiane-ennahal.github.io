Base de données MariaDB

Sécuriser MariaDB puis créer une base et un utilisateur dédiés à GLPI.

1. Sécurisation de MariaDB

La commande de sécurisation demande de définir le mot de passe root, de supprimer les utilisateurs anonymes et d'interdire l'accès root à distance.

sudo mysql_secure_installation

2. Connexion à MariaDB

sudo mysql -u root -p

3. Base et utilisateur GLPI

Création de la base, de l'utilisateur et attribution de tous les privilèges sur cette base seulement (principe du moindre privilège).

CREATE DATABASE db23_glpi;
GRANT ALL PRIVILEGES ON db23_glpi.* TO glpi_adm@localhost IDENTIFIED BY "MotDePasseRobuste";
FLUSH PRIVILEGES;
EXIT
