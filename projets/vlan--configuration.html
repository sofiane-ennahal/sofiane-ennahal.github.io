Configuration des commutateurs

Créer les VLAN, affecter les ports en mode access et passer les liens en trunk.

Principe

Les trois commutateurs sont configurés de la même façon. Les postes sont branchés sur le premier port libre de leur VLAN.

Configuration (Cisco IOS)

enable
conf t
vlan 110
 name ADMINISTRATIF
vlan 120
 name DEVELOPPEMENT
vlan 130
 name COMMERCIAL

interface range fa0/1 - 6
 switchport mode access
 switchport access vlan 110
interface range fa0/7 - 12
 switchport mode access
 switchport access vlan 120
interface range fa0/13 - 18
 switchport mode access
 switchport access vlan 130

interface range fa0/21 - 24
 switchport mode trunk

Trunk 802.1Q

Les ports 21 à 24 transportent plusieurs VLAN sur un même lien entre commutateurs, ce qui permet à un service d'être présent sur plusieurs étages.
